hello.core

This page is served on CoreNet.

A CoreNet service is an ordinary HTTP server. This one is a directory of files. No framework, no build step, no JavaScript.

How it got here

  1. The browser asked for hello.core.
  2. corenetd answered the DNS query with 127.0.0.1.
  3. The browser sent GET / HTTP/1.1 with Host: hello.core.
  4. corenetd looked the name up in its directory and passed the request to this server.

Serve it yourself

python3 -m http.server 8081 --directory examples/hello
corenet service add hello.core 127.0.0.1 8081
